# Reference

## Languages

Transcription, detected automatically: Bulgarian, Croatian, Czech, Danish, Dutch,
English, Estonian, Finnish, French, German, Greek, Hungarian, Italian, Latvian,
Lithuanian, Maltese, Polish, Portuguese, Romanian, Russian, Slovak, Slovenian, Spanish,
Swedish, Ukrainian.

Translation: English to and from 36 other languages, including Arabic, Chinese and
Japanese. Arabic speech is not recognized, so Arabic is a translation target only.

## Configuration

Precedence: command-line options, then `SPEECHLOOM_*` environment variables, then
`~/.config/speechloom/config.ini`. See `config.example.ini` in the repository root.
